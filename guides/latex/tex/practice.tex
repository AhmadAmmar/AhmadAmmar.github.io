\chapter{Good practice and version control}
\label{ch:practice}

\section{A tidy project}\label{a-tidy-project}

\begin{lstlisting}[language=text]
paper/
  main.tex        the document's skeleton
  sections/       one file for each section
  figures/        generated by scripts
  tables/         generated by scripts
  refs.bib
  code/           scripts that make the figures, tables and numbers
  build/          outputs, not tracked
\end{lstlisting}

\section{Version control}\label{version-control}

LaTeX is text, so Git handles it well. Put each sentence on its own line, so that a change shows as one changed sentence. Keep helper files out of Git with a \texttt{.gitignore}:

\begin{lstlisting}[language=text]
*.aux
*.log
*.out
*.toc
*.bbl
*.blg
*.synctex.gz
\end{lstlisting}

Tag each version you send out, as covered in the \href{../../git-ci/}{Git and automation guide}.

\section{Reproducible builds}\label{reproducible-builds}

A document is reproducible if someone else can rebuild it from your files.

\begin{itemize}
\tightlist
\item
  Record the commands in a README or a script.
\item
  Generate figures, tables and numbers with code.
\item
  Build in a clean folder now and then, because old helper files can hide faults.
\item
  Keep paths relative, never tied to your own machine.
\item
  Fix \texttt{\textbackslash{}date\{...\}} to a real date for a version, because \texttt{\textbackslash{}today} changes at every compile.
\end{itemize}

\section{Accessible documents}\label{accessible-documents}

\begin{itemize}
\tightlist
\item
  Use real headings, lists and captions.
\item
  Choose colours with good contrast that still work in greyscale.
\item
  Prefer colourblind-safe palettes.
\item
  Set the document\textquotesingle s title and language, for screen readers: \texttt{\textbackslash{}hypersetup\{pdftitle=\{...\}\}}.
\end{itemize}

\section{Working with others}\label{working-with-others}

Overleaf offers live co-editing, and it can sync with Git. Otherwise, agree who changes what, keep to one sentence per line, and use \texttt{latexdiff\ old.tex\ new.tex\ \textgreater{}\ changes.tex} to produce a marked-up comparison for readers who don\textquotesingle t use Git.
