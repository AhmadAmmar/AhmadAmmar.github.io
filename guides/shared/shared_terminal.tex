\section{The terminal, and how to read the commands here}

A terminal is a window where you type instructions to your computer instead of clicking. It looks severe, but it only does what you type, and most commands in this guide are safe to repeat.

In VS Code, open the \textbf{Terminal} menu at the top of the window and choose \textbf{New Terminal}. A panel opens at the bottom of the window with a line that waits for you to type. That line is called the prompt. It usually ends in \texttt{>} or \texttt{\$} and shows the folder you are in.

When this guide shows a command, type everything on that line, then press Enter. Where a block shows a line beginning \texttt{\$}, the \texttt{\$} stands for the prompt, so do not type it. The lines beneath it are what the computer prints back. Yours will match closely, although codes such as \texttt{1a2b3c4} will differ.

If a command prints something you did not expect, nothing is broken. Read the message, because it usually says what to do next. To stop a command that seems stuck, press Ctrl and C together.
