# Know your study area (draft)

Four notebooks for researchers from any discipline who need to understand a place from open data, with Quetta as the
worked example: 01 getting the data (OSM, Overture, WorldPop), 02 overlays and calculations, 03 maps and
interactivity (explore, folium, plotly, ipywidgets), 04 questions by discipline.

Edit `src/NN_*.py` and run `python build.py NN` (eo environment): the notebook is rebuilt and executed. Downloads go to
`notebooks/data/` (not tracked). Not yet wired into the guide pipeline (document.toml, chapters, web pages).
