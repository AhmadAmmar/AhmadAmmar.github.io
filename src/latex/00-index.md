This guide explains how LaTeX works and how to use it well, starting from nothing. It's also my own reference, so that I can rebuild my projects from scratch if I ever forget how they work.

LaTeX suits long documents with maths, numbered sections and references, because you describe the document's structure and it handles the layout. You write plain text, which also means every version can be tracked and compared.

## How to use it

Read in order if you're new. Each chapter builds on the last, and the code shown compiles as written. The [example files](examples/latex-examples.zip) include all of it, and the complete report comes together in the chapter on [references](references/).

Prefer one long page? [Read the whole guide on one page](full/).

## Getting LaTeX

- **To try it with nothing installed:** [Overleaf](https://www.overleaf.com) runs in the browser.
- **On your computer:** [MiKTeX](https://miktex.org) on Windows, [MacTeX](https://www.tug.org/mactex/) on macOS, or [TeX Live](https://www.tug.org/texlive/) on Linux.
- **An editor:** VS Code with the LaTeX Workshop extension, or TeXstudio.

The [official LaTeX documentation](https://www.latex-project.org/help/documentation/) and the [LaTeX Wikibook](https://en.wikibooks.org/wiki/LaTeX) are good references to keep at hand.
