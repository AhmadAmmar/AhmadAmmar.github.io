11. Troubleshooting and cheat sheet¶

11.1 Errors and what they mean¶

Symptom

Likely cause

Fix

Permission denied (publickey)

Wrong key, username or port, or the key is not installed yet

Check .ssh/config, and that the cluster has your key

Host identification warning

A login node you have not met, or a real problem

Read your cluster's guidance before accepting

scp: "No such file" with a stray "

Trailing backslash in a Windows path

Remove the backslash

scp: wrong port

-p instead of -P

scp uses capital -P

Killed on the login node

Too much memory on a shared node

Use srun or sbatch

CondaError: Run 'conda init'

Shell not set up for conda

conda init, then log in again; or call the environment's Python directly

EnvironmentLocationNotFound

The environment was never created, often as an earlier step failed

Scroll up and fix the first error

SRE module mismatch or strange Python errors

PYTHONPATH points at another Python's libraries

unset PYTHONPATH PYTHONHOME

No module named ... in a job

The job is using a different Python

Call your Python by its full path

rustup says no default toolchain

Only the installer is loaded

rustup default stable

Downloads fail in a job

Compute nodes may have restricted internet

Download on the login node first, and build offline

Permission denied on your own files

Read-only after copying

chmod -R u+w folder

$'\r': command not found

Windows line endings

sed -i 's/\r$//' script.sh

No log file appears

The --output folder does not exist

mkdir -p logs before you submit

State TIMEOUT

Hit the time limit

More --time, or a longer partition

State OUT_OF_MEMORY

Hit the memory limit

More --mem

Stuck on PD for ages

Busy, or you asked for too much

squeue -u $USER shows the reason; ask for less

Files vanished from scratch

Purged after no access

Keep copies elsewhere

Pasted lines ran in an odd order

Multi-line paste in a terminal

Paste one line at a time and check

The general method: read the first error rather than the last, as later errors are often consequences. Then search for its exact text.

11.2 Cheat sheet¶

## cluster: daily use
squeue -u $USER                                # what is running
sbatch job.sh                                  # submit
sbatch --array=0-9 job.sh args                 # submit an array
scancel <jobid>                                # cancel
tail -20 "$(ls -t logs/*.out | head -1)"       # newest log
sacct -X -P -S 2026-01-01 -u $USER -o JobID,JobName,Elapsed,State   # history
srun --cpus-per-task=1 --mem=4G --time=00:15:00 --pty bash          # interactive
module avail; module load <name>; module list  # software
quota -s; du -sh ~/project                     # storage
tar czf out.tgz folder; tar xzf out.tgz        # pack and unpack

## laptop
ssh kelvin                                     # log in
scp file kelvin:~/project/                     # upload
scp kelvin:~/project/file "D:\My Work"         # download
