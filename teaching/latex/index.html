This guide explains how LaTeX works and how to use it well, starting from nothing. It's also my own reference, so that I can rebuild my projects from scratch if I ever forget how they work.

LaTeX suits long documents with maths, numbered sections and references, because you describe the document's structure and it handles the layout. You write plain text, which also means every version can be tracked and compared.

How to use it

Read in order if you're new. Each chapter builds on the last, and the code shown compiles as written. The example files include all of it, and the complete report comes together in the chapter on references.

Prefer one long page? Read the whole guide on one page.

Getting LaTeX

  • To try it with nothing installed: Overleaf runs in the browser.
  • On your computer: MiKTeX on Windows, MacTeX on macOS, or TeX Live on Linux.
  • An editor: VS Code with the LaTeX Workshop extension, or TeXstudio.

The official LaTeX documentation and the LaTeX Wikibook are good references to keep at hand.
